# Calculator

A simple and interactive calculator built using **HTML, CSS, and JavaScript**. It provides a clean, user-friendly interface for performing basic arithmetic operations.

## Features

- Addition, subtraction, multiplication, and division
- Interactive buttons for entering numbers and operators
- Clear button to reset calculations
- Responsive and clean user interface
- Instant calculation results

## Technologies Used

- **HTML** – Structure of the calculator
- **CSS** – Styling and layout
- **JavaScript** – Calculator logic and functionality

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
